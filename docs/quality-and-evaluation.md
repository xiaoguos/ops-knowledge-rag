# 文档质量与分层评测

## 接入和质量复核

Markdown、TXT 和 DOCX 直接解析。PDF 逐页提取文字，缺少文字、出现替代字符或包含图像对象时，渲染后走本地 RapidOCR。图像对象也可能是标识或矢量内容，因此该判断偏保守，可能多做 OCR。

识别记录保留文字、坐标框、页码、识别分数、处理方式和警告。根据纵向重叠聚合行，再依据列起点对齐生成简单表格候选。不推测合并单元格，不宣称解决任意版面；多列正文和跨页表格需要人工确认。

OCR 为空、最低识别分数低于 0.85 或存在未确定的多列布局时，可调用显式配置的视觉模型。0.85 是路由阈值，不是文档正确率。未配置视觉服务也可由管理员对照原页补全文字；视觉服务失败不会伪造结果。

所有机器识别页进入 `awaiting_review`，不立即激活新版本。管理员逐页核对文字、数字、单位、否定词、错误码和表格行列；空页必须明确确认。复核保存原文件，修订稿另存。只有复核后的索引成功才切换有效版本，期间旧版本继续服务。

提交携带版本 ID 和报告摘要；后端加锁校验当前修订及状态，过期或重复提交返回 409。索引任务仍验证执行权，不能因为加入人工步骤而绕过原有版本竞争保护。

PDF 上限为 60 页，每页渲染不超过 800 万像素，转录不超过 32000 字符；单文档最多 2000 切片，单个原子表格/代码块最多 16000 字符。该限制不是完整的恶意文件沙箱；公开接收不可信文件仍需隔离进程、资源配额和安全扫描。

## 检索与会话上下文

默认保留原问题，并用规则处理部分口语和指代。`RAG_QUERY_REWRITE=1` 才启用模型改写；失败、超长或丢失错误码/路径/数字时回退。改写只影响检索文本，不改变服务端权限与版本过滤。

短块用于匹配；命中后补充相邻且同标题、同页的上下文，再按父内容去重。常规父上下文上限约 6000 字符，原子块另受 16000 字符限制。当前把父内容存入切片，不是独立的父文档图数据库。

会话只读取当前用户的最近 12 个问题，并排除依据已撤销部门权限的历史消息。最近 3 问各最多 500 字符，较早问题提取为最多 600 字符的话题摘要。它用于指代，不作为业务事实依据，也不是跨会话长期记忆。

## 分层指标与分母

| 层次 | 检查项 | 解释 |
| --- | --- | --- |
| 解析 | 页数、来源页码、识别字段、表格候选、空页确认 | 合成扫描件走真实 OCR；复杂版面还需扩充人工标注集 |
| 检索 | Recall@5、All-evidence@5 | 前 5 条证据中覆盖的相关文档数 / 该题相关文档总数；无答案题不计入 |
| 引用契约 | 引用 ID 有效、引句位于原文 | 只统计实际非拒答输出；不代表语义正确 |
| 拒答 | 输出拒答是否符合标注预期 | 包括应拒答与应回答，失败请求另计 |
| 权限 | 权限用例返回证据是否全部在授权部门 | 单独统计权限用例，不用管理员问题稀释分母 |
| 人工语义 | 证据支持、事实正确、要点完整 | 评审者写依据；未标注保留 null，公开已评/未评数量 |

## 运行方法

```bash
# 真实 BGE，调用当前 Knowledge 入口，不调用付费生成模型
python -m scripts.evaluate_production

# 有界真实模型回归，使用后端环境中的模型配置
python -m scripts.evaluate_production --live --cases r01,r05,r07,r22,r29,r31,r34,r36 --output docs/live-evaluation.json

# 导出待填写的人评表；输出文件必须尚不存在
python -m scripts.review_evaluation --report docs/live-evaluation.json --template reviews.json

# 人工完成标签后再导入；每条必须有评审人、带时区时间、三个判断和依据
python -m scripts.review_evaluation --report docs/live-evaluation.json --labels reviews.json --output reviewed-evaluation.json
```

人评表绑定数据集摘要和本次结果文件摘要，不能把旧版本标签直接套到新回答上。生产资料评测结果可能包含敏感内容，发布前必须脱敏；仓库内记录只使用合成资料。

## 本次结果与边界

2026-09-23：36 条自建合成回归用例中，30 条有相关文档，3 条权限题，3 条无答案题。BM25、向量、混合检索及上下文扩展在这个小语料上均达到 Recall@5=1.0，未观察到方案间增益。这是回归覆盖，不是独立业务准确率。

8 条真实模型用例完成生成或拒答，调用错误为 0；5 条应回答、3 条应拒答，拒答匹配 8/8；5 条非拒答输出均通过引用契约检查。人工语义合格率尚未标注，保持 null。样本过小，不用于证明 100% 问答准确或生产 SLA。

扫描 PDF 的浏览器验收包括上传、OCR、表格候选、对照原页修订、索引、真实问答、来源页、多轮追问和历史回看。真实记录见 `ocr-browser-acceptance.json`；视觉接口与模型改写记录见 `vision-acceptance.json`。自动化复核操作不计为独立人工标注。

下一阶段应增加低分辨率、倾斜页、多栏、合并单元格、相似错误码、同主题不同版本和困难负例，并由不参与开发的评审者盲评。调参集和最终测试集需要分离，不能反复根据同一份测试答案优化后再声称泛化提升。
